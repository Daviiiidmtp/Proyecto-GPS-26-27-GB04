# EP-05 Sistema de Notificaciones

- **Goals:** G-02
- **Baseline:** Versión Inicial
- **Boundary:** Alertas internas dentro de la propia web, no se enviarán correos electrónicos reales por ahora.

## Epic outcome
Que los usuarios se enteren rápido cuando la tienda publique un nuevo torneo o evento para que no se queden sin plaza.

## Stories

### 1. US-11 Notificación de eventos
> Como usuario, quiero recibir alertas cuando se publique un nuevo evento.

- **Priority:** Could
- **Estimate:** 1.5 h-p
- **Predecessors:** US-04

#### Acceptance criteria
- **US-11-AC-01:** La web tiene que tener un icono de campana arriba que muestre un aviso visual cuando hay algo nuevo.
- **US-11-AC-02:** Al pulsar la campana, sale una pequeña lista desplegable con las últimas novedades o alertas sin leer. 
- **US-11-AC-03:** Si pinchas en la notificación, te lleva directamente a la página de ese evento concreto para poder verlo o apuntarte.
