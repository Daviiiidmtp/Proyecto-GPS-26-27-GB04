# Objetivo y alcance del proyecto

## Objetivos

| Id   | Objetivo                        | Resultado esperado                                                                                                                        |
| ---- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| G-01 | Visualización de stock          | El cliente puede ver los productos disponibles de la tienda de forma on-line sin necesidad de asistir presencialmente al recinto.         |
| G-02 | Inscripción en eventos          | El cliente puede inscribirse libremente a los distintos eventos organizados y hospedados en el local físico.                              |
| G-03 | Comunicación entre usuarios     | El cliente puede comunicarse con otros usuarios mediante un foro habilitado por el local.                                                 |
| G-04 | Implementación de accesibilidad | Todos los usuarios pueden navegar por el catálogo/torneos utilizando funcionalidades comprensibles y adaptadas, en caso de ser necesario. |

## Indicadores de éxito

| Id   | Objetivo | Meta                                                                                                                          |
| ---- | -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| M-01 | G-01     | El cliente obtiene la información que desea de la página de la tienda.                                                        |
| M-02 | G-02     | El cliente visualiza el estado de los eventos que le interesan y se puede inscribir exitosamente en aquellos con aforo libre. |
| M-03 | G-03     | El cliente puede abrir hilos en el foro y responder en conversaciones activas con una cuenta verificada.                      |
| M-04 | G-04     | El cliente navega sin dificultades por la página, la cual se adapta a sus necesidades.                                        |

## Alcance incluido

El proyecto incluye:

- **S-01**: Un recorrido esencial y coherente para la búsqueda, selección y simulación de compra de productos en la tienda.
- **S-02**: Un sistema para consultar el calendario de torneos y completar un flujo de inscripción.
- **S-03:** Un conjunto controlado de productos y eventos completamente ficticios.
- **S-04:** Funciones de administración para gestionar los datos de la demostración.

## Exclusiones

Se excluyen las siguientes características:

- **E-01:** Datos reales de usuarios, dado que se utilizarán datos ficticios.
- **E-02:** Cualquier clase de operación monetaria que no sea simulada.
- **E-03:** Registros no controlados de nuevos usuarios.

## Restricciones

Se respetarán las siguientes condiciones:

- **R-01:** No se utilizarán ninguna clase de datos personales reales.
- **R-02:** Se emplearán únicamente las tecnologías aprobadas.

## Trazabilidad

La cadena de trazabilidad será:

**Misión -> Objetivos -> Épicas -> Historias -> Tareas -> Código y pruebas -> Evidencias**

Cualquier épica que no contribuya a ningún objetivo se considera fuera del alcance hasta que se apruebe un cambio en `goals.md`.

## Gestión de cambios

Cualquier clase de modificación requiere:

- Revisión por parte del equipo.
- Aprobación del Product Owner.
- Registro de la decisión.
- Revisiones del roadmap, especificaciones, gestor de tareas y capacidad.
- Actualización de todas las referencias afectadas.
